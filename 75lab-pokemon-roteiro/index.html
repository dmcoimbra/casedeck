Por que o roteiro é modularWhy the protocol is modular

Quanto menos especializada a loja, menor o portfólio Pokémon e mais rápida a visita. Uma megaloja de brinquedos tem as seis categorias; uma papelaria ou um bazar costuma ter só TCG. Cada módulo só abre para as categorias que existem na loja.The less specialized the store, the smaller the Pokémon range and the faster the visit. A toy megastore carries all six categories; a stationery or variety store usually has TCG only. Each module opens only for the categories the store actually has.

Por que as regras são fixasWhy the rules are fixed

Toda regra de medição definida agora vira padrão das próximas ondas. Mudar depois quebra a comparação loja a loja.Every measurement rule set now becomes the standard for future waves. Changing it later breaks store-by-store comparison.

Os módulos são os blocos de dados. O percurso é a ordem física da visita: uma volta de reconhecimento, uma estação por categoria e o fechamento. Cada módulo traz o que registrar e a regra de campo.Modules are the data blocks. The path is the physical order of the visit: one walk-through, one station per category, then close-out.
